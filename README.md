# ResearchRAG

ResearchRAG is an early-stage Python project for building a production-oriented Retrieval-Augmented Generation (RAG) system for research papers and technical documents.

## Current Project Goal

Set up a clean, minimal project scaffold that can be extended step-by-step into a robust RAG pipeline.

## Planned RAG Pipeline

Documents → Text Extraction → Chunking → Embeddings → Vector Database → Retrieval → Reranking → LLM → Citations

## Roadmap

1. Embeddings and vector similarity
2. PDF ingestion
3. Chunking
4. FAISS retrieval
5. LLM generation
6. Hybrid search
7. Reranking
8. RAG evaluation
9. Production deployment
